# Python 依赖库安装器

基于 tkinter 的图形化 Python 依赖库管理工具，按分类批量安装、版本检查和一键更新。

## 功能

- **pip 启动自检**：打开程序自动检查 pip 是否可用、版本是否最新，顶部状态栏清晰显示
- **一键修复 pip**：点击「🔧 修复 pip」弹出修复对话框，三种方案任选（升级/ensurepip/手动）
- **分类管理**：11 大类依赖库（游戏开发、AI/机器学习、Web 开发、爬虫/网络、数据可视化、数据库、图像/音视频、办公自动化、异步/并发、加密/安全、工具链）
- **批量安装**：勾选需要的库，一键安装
- **批量卸载**：勾选不需要的库，确认后一键卸载
- **版本检查**：对比已安装版本与 PyPI 最新版本
- **一键更新**：批量升级到最新版本
- **扫盘**：扫描系统中所有 Python 安装位置，列出每个环境的包列表

## 运行

```bash
cd D:\allin\tools\requirements
python requirements.py
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `requirements.py` | 主程序（tkinter GUI） |
| `requirements_categories.json` | 依赖分类与库名配置，可按需增删 |
| `失败日志.txt` | 安装失败记录 |

## 环境要求

- Python 3.8+
- tkinter（标准库自带）

## 注意事项

- 程序启动会自动检查 pip 状态，如有问题顶部会显示红色提示
- 部分库（如 tensorflow）对 Python 版本有特定要求
- 安装/更新失败会自动记录到 `失败日志.txt`
